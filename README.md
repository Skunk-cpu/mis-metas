# Mis Metas

Aplicación web para organizar objetivos, ahorros y gastos.

## Publicación
GitHub → Settings → Pages → Deploy from a branch → main / (root) → Save.

Dirección prevista: https://skunk-cpu.github.io/mis-metas/

Los datos se guardan en el navegador del dispositivo, no en GitHub. Exportá copias de seguridad JSON periódicamente. Los precios se consultan manualmente en Internet.
